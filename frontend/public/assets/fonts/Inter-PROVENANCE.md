# Inter delivery assets

The commercial Studio X OS HTML serves the existing Inter UI typeface locally.
These are unmodified Google Fonts Inter v20 variable WOFF2 subsets, normal
style, weights 100–900 and optical sizes 14–32. Latin is preloaded; Latin
Extended is requested only when its Unicode range appears. Other scripts use
the existing system fallback stack. The personal Team Alpha HTML retains its
original Google Fonts configuration.

Retrieved on 10 November 2026 from the official Google Fonts CSS API:
`https://fonts.googleapis.com/css2?family=Inter:opsz,wght@14..32,100..900&display=swap`.
