# Commercial homepage assets

The homepage serves its artwork and fonts from the application’s public assets. Brand names and product marks belong to their respective owners.

| Asset | Source |
| --- | --- |
| Studio X OS wordmark, symbols, lockup, and icons | Studio X OS owner-supplied artwork. The public brand package contains its asset index. |
| Google Calendar logo | Unmodified [Google Calendar product artwork](https://www.gstatic.com/images/branding/productlogos/calendar_2020q4/v13/192px.svg). [Google brand guidance](https://about.google/brand-resource-center/products-and-services/). |
| Gmail logo | Unmodified [Gmail product artwork](https://fonts.gstatic.com/s/i/productlogos/gmail_2020q4/v8/192px.svg). [Google brand guidance](https://about.google/brand-resource-center/products-and-services/). |
| WhatsApp logo | The original 2026 green digital glyph from the [WhatsApp Brand Resource Center](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/). |
| Fluid footage and poster frames | The reviewed hero, mobile and workbench films from Scene AI. The public media manifest records the source and encoding of each local rendition. The poster files use the corresponding reviewed frames. |
| Inter, Manrope and Urbanist | The public `assets/fonts` folder contains the bundled SIL Open Font Licenses. |
| Studio X OS screenshots | Captured from the fictional Studio X OS sample workspace. |
